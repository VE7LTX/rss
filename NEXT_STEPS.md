# Next Steps

This document keeps the roadmap sequenced and low-risk. Items marked done reflect current repo state.

## 1) Controlled Vocabularies (done)

- Categories, tags, and locales are in `data/`.
- Keep the lists stable and make changes intentionally.

## 2) Feed Record Schema (done)

- Schema lives in `docs/schema.md`.
- Validation enforces required fields and vocabulary membership.

## 3) Validation & Health Checks (partial)

- Schema validation is implemented in `scripts/validate/validate.py`.
- Next: add optional network checks (HTTP status, feed parse, last item date).

## 4) Generate Outputs (done)

- Build outputs are generated by `scripts/build/build.py` into `dist/`.
- Includes JSON, CSV, OPML, indexes, and demo items for the UI.

## 5) Prototype Browser UI (done)

- Static UI in `public/` loads data from `dist/`.
- Supports filters, search, selection, and demo live updates.

## 6) Expand Seed Feeds (next)

- Target 50-100 feeds across 12-18 categories.
- Balance regions and source types.
- Validate new entries before commit.

## 7) Live Updates MVP (next)

- Replace demo items with real feed fetches.
- Cache results locally and update on refresh.
- Keep the UI static and fetch via a lightweight local service.

## 8) CI and Release Hygiene (next)

- Add a basic CI workflow for validation and build.
- Consider a release tag when outputs are refreshed.
