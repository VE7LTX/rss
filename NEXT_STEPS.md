# Next Steps

This document tracks sequencing for the MVP and beyond. Items marked done are complete in the current repo state.

## 1) Controlled vocabularies (done)

- Categories, tags, and locales are defined in `data/`.
- Keep the lists stable; review changes intentionally.

## 2) Feed record schema (done)

- Schema lives in `docs/schema.md`.
- Validation enforces required fields and vocabulary membership.

## 3) Validation tooling (done)

- Schema validation is implemented in `scripts/validate/validate.py`.
- JSON reports can be generated with `--json` or `--out`.

## 4) Build pipeline (done)

- Outputs are generated by `scripts/build/build.py` into `dist/`.
- Includes JSON, CSV, OPML, indexes, and demo items.

## 5) The RSS Encyclopedia UI (done)

- Static UI in `public/` loads data from `dist/`.
- Supports filters, search, selection, and demo updates.

## 6) Unit tests (done)

- Tests live in `tests/`.
- Run with `python -m unittest discover -s tests`.

## 7) Expand seed feeds (done)

- Seeded 60 feeds across 18 categories, 11 regions, and 7 source types.
- Validation and build outputs updated to match the expanded dataset.

## 8) Health checks (next)

- Add optional network validation (HTTP status, parse results, last item date).
- Cache results to avoid throttling or rate limits.

## 9) Live updates MVP (next)

- Replace demo items with real feed fetches.
- Cache results locally and update on refresh.
- Keep UI static and use a lightweight local service for fetching.

## 10) CI and release hygiene (next)

- Add CI for validation, build, and tests.
- Consider tagged releases when outputs are refreshed.
